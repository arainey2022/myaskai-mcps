# Security

The My AskAI MCP server is public and read-only. It uses published My AskAI documentation and pricing information. It does not provide access to private My AskAI accounts, customer conversations, or customer data.

## Report a security issue

Do not open a public issue for a suspected security problem.

[Report the issue privately through GitHub](https://github.com/arainey2022/myaskai-mcps/security/advisories/new). Include the affected endpoint, the expected result, the actual result, and clear steps to reproduce the problem.

We will review the report and reply through the private GitHub advisory.
